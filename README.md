# homebrew-tap

Personal Homebrew tap for [svclimb](https://github.com/svclimb)'s tools.

Formulas here are generated and published automatically by [GoReleaser](https://goreleaser.com/)
whenever a new release is tagged in the source repository — don't edit them by hand.

## Install

```bash
brew tap svclimb/tap
brew install kwatch
```

or in one line:

```bash
brew install svclimb/tap/kwatch
```

## Tools

| Formula | Source |
|---|---|
| [`kwatch`](Formula/kwatch.rb) | [svclimb/kwatch](https://github.com/svclimb/kwatch) |
